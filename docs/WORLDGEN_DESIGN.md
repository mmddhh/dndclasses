# DND 世界生成设计方案

> 状态：设计冻结前的实施基线。  
> 目标：Minecraft Forge 1.20.1，替换主世界，生成 62,720 × 62,720 的双轴环形世界。  
> 本文优先记录已确认的决定、验收指标和实现顺序，避免实现过程中反复改设计。

---

## 1. 已确认的世界参数

| 项目 | 决定 |
|---|---|
| 世界边长 | 62,720 方块 |
| 拓扑 | X/Z 双轴环形（torus） |
| 显示坐标 | `[-31,360, 31,360)`，中心 `(0,0)` |
| `min_y` | -128 |
| `height` | 640 |
| `max_y` | 511 |
| 海平面 | 63 |
| 区块 | 16 × 16 |
| 地形区域 | 4,096 × 4,096 |
| 主世界 | 最终替换主世界，不做“进入世界后再传送” |

### 1.1 坐标系

- 标准坐标：`[0, 62,720)`，用于存储和哈希。
- 显示坐标：`[-31,360, 31,360)`，用于玩家、地图和命令。
- 所有邻域、河流、板块边界计算必须在环形拓扑上取最短距离。
- 接缝处必须保持高度、群系、河流连续。

### 1.2 高度预算

```text
海洋最深：约 -140
海平面：63
平原：约 67
丘陵基底：约 70
丘陵内部：78–85
高原面：约 163
高山：150–260
超高山：300–400
世界最高：511
```

## 2. 总体生成管线

```text
seed
 -> 板块图（板块形状、类型、边界）
 -> 基础高程（大陆/海洋/山脉/裂谷/海沟）
 -> 地形类型（平原/丘陵/高原/盆地/山地）
 -> 气候（纬度温度、海拔、湿度、风带、季节）
 -> 宜居度
 -> 历史推演（文明、灾害、神迹）
 -> 地形事件层（裂谷、陨石坑、火山、神迹等）
 -> 河流/湖泊
 -> 聚落/道路/遗迹
 -> chunk 生成
```

### 2.1 两阶段历史

历史依赖宜居度，但不能反过来在已生成区块上修改地形，因此采用：

```text
阶段 A：基础地形 -> 气候 -> 宜居度 -> 历史
阶段 B：历史事件作为确定性地形修改层，在 chunk 生成时查询并应用
```

事件层必须只依赖：

```text
seed + 事件记录（中心、半径、类型、年份、强度）
```

因此：

- 同一个事件层在游戏和离线图中完全一致；
- 不依赖区块生成顺序；
- 不修改已生成区块也能保证新生成区块一致。

## 3. 板块模型

### 3.1 定位

采用**运动学板块模型**，不模拟完整地幔对流。

生成一张低分辨率板块图，例如：

```text
245 × 245（256 方块/格）
或 980 × 980（64 方块/格）
```

每个板块记录：

```text
id
大陆型 / 海洋型
种子中心
运动方向
边界类型
板块年龄
```

### 3.2 板块边界

| 边界 | 地形结果 |
|---|---|
| 大陆-大陆汇聚 | 高大山脉、超高山、尖顶 |
| 大陆-海洋俯冲 | 海沟、岛弧、火山 |
| 离散边界 | 裂谷、断陷盆地、海岭 |
| 转换边界 | 走滑断层、线性谷地、地震带 |

### 3.3 基础高程

```text
基础高程 =
    板块基准高度
  + 大陆地壳抬升
  + 汇聚边界造山
  - 离散边界裂谷
  - 俯冲海沟深度
  + 低频噪声
```

### 3.4 板块与奇观

奇观应优先落在构造带上：

- 裂谷 -> 离散边界；
- 火山 -> 俯冲带/热点；
- 超高山 -> 大陆碰撞带；
- 海沟 -> 俯冲带；
- 陨石坑 -> 独立随机点，不依赖板块。

## 4. 地形类型与验收

### 4.1 类型

```text
PLAINS
HILLS
PLATEAU
BASIN
MOUNTAINS
OCEAN
```

地形类型由**低频区域掩码**决定，不是按高度分档。

原则：

```text
平原是默认基底
丘陵是平原上的有限斑块
高原是独立抬升的台地
盆地是独立凹陷
山地是连续山脉
```

### 4.2 平原

- 基准高度：`海平面 + 4`
- 核心区域验收：
  - 在 256 × 256 方块内
  - `最高 - 最低 ≤ 7`
- 不允许出现连续小丘。
- 河流应缓慢、弯曲。

### 4.3 丘陵

- 基底比平原高 3 格。
- 丘陵内部高低差：8–15 格。
- 形态是柔和的曲线隆起，不是“指压板”式小鼓包。
- 丘陵之间应保留平原或谷地。
- 覆盖率目标：平原为基底，丘陵只占局部斑块。

### 4.4 高原

- 高原面：`海平面 + 100`（约 163）。
- 内部起伏：≤ 7 格，和平原类似。
- 与平原的区别主要是：
  - 海拔；
  - 温度；
  - 植被/积雪；
  - 边缘陡坎。
- 边缘过渡：50–100 格。
- 面积应足够大，至少约 1,000 × 1,000 方块。

### 4.5 山地

- 普通山脉：150–260 格。
- 超高山：300–400 格。
- 超高山必须尖顶，不是圆包。
- 必须有连续主山脊 + 支脉。
- 山地边缘不能是整圈垂直高墙，需要有坡脚和过渡。
- 雪线由温度决定，不由“山地类型”决定。

### 4.6 盆地

- 内部低、边缘回到平原。
- 中心可以形成湖泊或内流盆地。
- 不允许变成随机圆坑。

### 4.7 海洋

- 大陆架：浅；
- 大陆坡：快速加深；
- 深海平原：120–200 格深；
- 海沟：可超过 200 格。
- 海岸线必须有侵蚀感，不是规则圆形。

## 5. 气候

### 5.1 温度

温度主导因素：

```text
纬度（大尺度）
+ 海拔（中尺度）
+ 季节（时间）
+ 小噪声（只做点缀）
```

要求：

- 赤道高温；
- 两极低温；
- 高山随海拔降温；
- 小噪声不能直接决定群系切换。

### 5.2 风带

按现实纬度风带：

```text
赤道附近：信风（东风）
中纬度：西风
极地：极地东风
```

季节变化可引入季风，但不能让全球风向随机跳变。

### 5.3 湿度

湿度来源：

- 海洋距离；
- 迎风/背风；
- 山脉雨影；
- 河流/湖泊；
- 纬度带。

山脉必须作为气候分割线：

```text
迎风坡湿润
背风坡干旱
```

### 5.4 四季

```text
1 季 = 20 游戏日
1 年 = 80 游戏日
温度季节振幅：±8°C
```

季节只影响：

- 温度；
- 雪线；
- 水面结冰；
- 积雪/融雪。

**不改变群系判定。**

### 5.5 积雪与结冰

```text
温度 <= 0°C：积雪 / 水面结冰
温度 0–3°C：雪层过渡
温度 > 3°C：无雪
```

要求：

- 赤道高山不一定积雪；
- 雪线随季节上下移动；
- 河面结冰按水面高度温度；
- 过渡带不能是硬切。

## 6. 河流与湖泊

### 6.1 河流要求

- 平滑曲线，不能是 D8 直角折线；
- 河面不得高于周围地面；
- 从高向低流，不允许上坡水；
- 下游逐渐变宽；
- 河床在水面下；
- 河岸完整包裹水体；
- 河流接入湖泊/海洋；
- 河流湿度影响沿岸群系。

### 6.2 湖泊

- 只出现在真正封闭洼地；
- 湖面不高于出口；
- 湖泊大小不应全部是圆坑；
- 湖岸可以有不规则小湾。

### 6.3 水文实现

采用区域化水文：

```text
Region 4096 × 4096
 -> 采样高度
 -> 优先洪泛填洼
 -> D8 流向
 -> 汇流累积
 -> 河道路径
 -> 平滑/重采样
 -> 连续水面高度
```

河流水面高度必须单调下降。

## 7. 历史事件层

### 7.1 事件类型

- 神迹；
- 神罚；
- 魔法事故；
- 地震；
- 陨石；
- 火山；
- 洪水；
- 海啸；
- 瘟疫/人口锐减；
- 战争。

### 7.2 可见结果

历史必须在地形上可见：

- 废弃河道；
- 地震断层；
- 熔岩掩埋城市；
- 陨石坑/环形湖；
- 神迹圣泉；
- 裂谷中的遗迹；
- 海啸后的盐碱地；
- 瘟疫后的废弃聚落。

### 7.3 事件字段

```text
类型
中心坐标
半径
强度
年代
来源（神/文明/自然）
```

事件层必须可序列化到世界存档。

## 8. 奇观

实现顺序：

1. 裂谷；
2. 巨型山洞入口；
3. 地下洞穴；
4. 陨石坑；
5. 火山/神迹。

### 8.1 裂谷

- 位于离散板块边界；
- 长条状；
- 两壁陡但非全垂直；
- 底部可有河/湖/熔岩；
- 边缘有崩塌碎石。

### 8.2 巨型山洞入口

- 地表可见的巨大洞口；
- 与地下洞穴系统相连；
- 不是简单圆井；
- 入口有崩塌堆积。

### 8.3 地下洞穴

- 与地表洞穴区分；
- 3D 噪声/管道系统；
- 不破坏地表太多；
- 可连接地下河/岩浆。

### 8.4 陨石坑

- 环形坑；
- 中央峰可选；
- 环形湖/湿地；
- 外围破碎带；
- 陨铁/玻璃化岩石。

### 8.5 火山/神迹

- 火山锥/破火山口；
- 熔岩管/黑曜石；
- 神迹根据神系设计，后期接入。

## 9. 聚落、道路与结构

### 9.1 规模

以原版村庄为基准：

```text
村庄      1.0×
镇        1.5×
小城市    2.0×
大城市    3.0×（小城市 1.5 倍）
首都      4.2×（小城市 2.1 倍）
```

人口锐减时按人口比例缩小。

### 9.2 选址

聚落必须参考：

- 宜居度；
- 河流/海岸；
- 坡度；
- 历史事件；
- 文明边界。

### 9.3 地基

- 陡峭地形不能悬空；
- 可以挖平；
- 可以填地基；
- 河岸/悬崖需要挡土墙/桩基；
- 遗迹可以残破、半埋、坍塌。

### 9.4 道路

- 连接聚落；
- 避开陡坡/深海；
- 河流上应有桥/渡口；
- 历史事件后道路可废弃/改线。

## 10. 性能

### 10.1 目标

- 区块生成不能出现“几秒一个区块”；
- 不能依赖全局烘焙；
- 不能出现异步水文竞态；
- 不能要求玩家先执行命令才生成河流。

### 10.2 策略

- 区域懒生成 + LRU 缓存；
- 每列高度/地形掩码缓存；
- 区域水文只构建当前区域；
- 相邻区域只查已缓存；
- 表面高度粗扫 + 细化；
- 高度、群系、河流共用同一份区域数据；
- 避免每个方块重复计算 landform。

### 10.3 禁止

- 全局 980×980 每区块重算；
- 离线图安装河网给生成器；
- 服务器启动时同步烘焙整个世界。

## 11. 主世界替换

最终必须：

```text
创建世界时使用自定义 ChunkGenerator 作为主世界
```

不是：

```text
进入原版世界 -> 命令传送到自定义维度
```

需要：

- 自定义 world preset / dimension；
- 主世界 `LevelStem` 使用 `dndclasses:terrain`；
- 出生点选址；
- 世界边界 62,720；
- 旧存档迁移策略另定。

## 12. 验收指标

### 12.1 平原

在 256 × 256 区域内：

```text
max(height) - min(height) <= 7
```

### 12.2 丘陵

```text
基底 = 平原 + 3
内部 max - min = 8–15
```

### 12.3 高原

```text
平台面高度约 sea + 100
平台内部 max - min <= 7
边缘过渡 50–100 格
```

### 12.4 山地

```text
普通山脉 150–260
超高山 300–400
必须有连续山脊
```

### 12.5 海洋

```text
深海 >= 120
海沟 >= 200
```

### 12.6 河流

```text
河面不高于周围地面
下游水面不高于上游
河道为平滑曲线
河宽下游递增
```

### 12.7 雪/冰

```text
温度 <= 0：雪/冰
过渡带：雪层
赤道高山不强制积雪
```

## 13. 当前实现状态

### 已存在

- `WorldTopology`：62,720 环形拓扑；
- `TerrainModel`：旧 2D 大陆/气候；
- `TerrainDensity`：3D 密度 + landform 目标；
- `TerrainLandform`：平原基底 + 丘陵/山地/高原/盆地掩码（仍在调）；
- `RegionalHydrology`：4,096 区域 D8 水文；
- `TerrainChunkGenerator`：自定义区块生成器；
- `TerrainBiomeSource`：群系映射；
- `DensityMapSampler`：离线图；
- `HydrologyService`：离线图视图。

### 已知问题

- landform 掩码频率/覆盖率仍会造成连续丘陵或大斜面；
- 平原核心尚未稳定满足 ≤7；
- 河流仍有折线、上坡、水面不连续；
- 区块加载仍偏慢；
- 结构/历史/奇观尚未接入；
- 主世界尚未替换。

### 技术债

- 旧的 2D `TerrainModel` 与 3D `TerrainDensity` 仍有重复定义；
- `TerrainLandform.type` 与真实密度表面曾经不一致（已修 F3，但架构仍需统一）；
- 河流和地形高度尚未共用同一份区域数据；
- 离线图和游戏仍可能使用不同采样路径。

1. 板块图 + 基础高程；
2. 地形类型掩码 + 平原/丘陵/高原/山地函数；
3. 海洋深度；

5. 河流/湖泊；

## 15. 非目标

- 不追求真实地质时间尺度的板块漂移；
- 不复制 TFC/Epic-Terrain 代码；
- 不做完整流体模拟；
- 不在已生成区块上事后大规模改地形；
- 不做“进入世界后再传送到测试维度”的最终方案。
